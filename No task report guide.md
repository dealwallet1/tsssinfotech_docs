# How to View the Employees Without Tasks Report

**Module:** Employee Analytics Dashboard
**For:** Administrators, HR managers, Project managers

---

## Step 1: Open the report

**Option A: top menu**
1. Open the **Employee Analytics** app.
2. Click **Employees Without Tasks** in the top bar.

**Option B: dashboard sidebar**
1. Open **Employee Analytics → Dashboard**.
2. Click **No-Task Report** in the left sidebar.

> The report is available only to users in the **HR Manager** or **Project Manager** group. If you cannot see the menu, ask an administrator to add one of these groups to your user.

## Step 2: Choose the period

Select a value in the **Period** field:

| Period | What it shows |
|---|---|
| Today | Today only |
| Tomorrow | Tomorrow only |
| Next Week | Next Monday to next Sunday |
| Specific Date | One date you pick |
| Custom Date Range | A From date and a To date you pick |

- For **Specific Date**, pick the date in the **Specific Date** field.
- For **Custom Date Range**, pick **Date From** and **Date To**.

## Step 3: (Optional) Choose a team

Select a **Team** to see only that team's employees. Leave it empty to see everyone.

## Step 4: Click Generate

Click **Generate**. The list of employees without tasks appears below the filters.

> Click **Generate** again every time you change a filter.

## Step 5: Read the list

| Column | Meaning |
|---|---|
| Employee | Employee with no task in the selected period |
| Team | The employee's department |
| Last project | Project of the employee's most recent task |
| Tasks in period | Number of tasks in the period (always 0) |
| Period from / Period to | The date range that was checked |
| Last task due | Due date of the last open task that ended before the period |
| Next task starts | Start date of the next open task that begins after the period |
